        How to use the lab

        1. Watch the home. Every device shares one Wi-Fi network. Packets travel device → router → SHIELD-IoT → destination: cyan is allowed, amber is flagged, red is dropped.
        2. Control devices. Pick a device in the Home network list or click it in the 3D view, then use its card: switch lights, set the AC, start the washer or speak to Alexa. Each command is real MQTT traffic through the hub.
        3. Plug in the unknown device. Its MAC address is not in the home inventory, so SHIELD-IoT raises an alert and, in Prevent mode, blocks it at the router.
        4. Tune the sensor. Switch evidence layers, the ML threshold and auto-blocking in the SHIELD-IoT panel. Detect only raises alerts without dropping anything.
        5. Inspect packets. The Packet log shows the last 200 packets; click one to see its fields and why SHIELD-IoT allowed, flagged or dropped it.

        Space pause or resume · Esc clear the selection · drag to orbit, scroll to zoom

        The detection layers follow Anirudh Sharma's SHIELD-IoT research (NIT Hamirpur). The ML layer is a surrogate tuned to the book's frozen LightGBM baseline, not the trained model, and this version has no attack launcher.
